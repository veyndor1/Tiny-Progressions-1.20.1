# Security policy

## Scope

This policy covers the Minecraft 1.20.1 port in this repository. Report issues affecting Minecraft, Forge, or another dependency to the appropriate upstream project when applicable.

## Report a vulnerability

Use GitHub's **Report a vulnerability** option in this repository's Security tab:

[Submit a private vulnerability report](https://github.com/veyndor1/Tiny-Progressions-1.20.1/security/advisories/new)

Include affected versions, reproduction steps, the observed impact, and a minimal example. Keep account credentials and unrelated personal information out of the report. Do not disclose active exploits or private server information in public issues.

## Supported release

The current `4.0.0-alpha.1` prerelease is the available maintenance target. No response-time or universal compatibility guarantee is made.

## Downloads

Obtain the player jar from this repository's Releases page and compare its SHA-256 checksum with the release checksum file. A checksum verifies matching bytes; it does not independently prove that software is vulnerability-free.
